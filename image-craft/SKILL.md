# image-craft · 图片心动方法论

一套从"维度定义 → 生成 → 诊断"的完整方法论。
回答一个问题：**什么样的图片让人心动，怎么造出来，怎么测它断在哪。**

当用户要生成图片或诊断图片时，按本 skill 流程走。

---

## 核心心法

1. **好看 ≠ 心动**。技术参数堆得出好看，心动靠的是叙事 / 瞬间 / 留白 / 距离感这几个特定维度。
2. **偏科，不要平均用力**。技术层做到 80 分保底，把火力集中压在 1~2 个心动层，主动牺牲 1 层。平均用力 = 安全牌 = 最无聊的一档。
3. **生成是正向进攻，诊断是逆向归因**。两件事方向相反，别拿防守清单去进攻。

---

## 触发场景

- **生成场景**：用户要生成/创作图片、写图片 prompt、设计图片生成方案
- **诊断场景**：用户拿图来评估、问为什么不满意/不动人、要改图

---

## 场景一：生成图片

走六步 checklist 协议，每步：**指示 + 必须输出 + 勾选**。全勾才进下一步。详见 [references/image-generation-guidelines.md](references/image-generation-guidelines.md)。

### 第一步：问方向
**指示**：分析任务→给推荐→抛4选项→等用户选
**必须输出**：方向选择题（A/B/C + D，含推荐标）
- [ ] 推荐标只给一个，理由具体到任务非套话
- [ ] 宽泛任务（写真/人像）先追问细分，未盲推
- [ ] 未自行出图，等用户选

铁律：没选不准出图；"都要"指 E 才有效；E 分两段（第一段三方向各出配方+完整prompt，共3套，不出图，等用户确认；确认后第二段三方向各出3张变体，共9张，不逼用户回头挑单一方向，不准黑箱）。

### 第二步：自动选参出方案（不追问变量）
**指示**：从 [references/image-structure-dimensions.md](references/image-structure-dimensions.md) 选八层→出偏科方案
**必须输出**：类型 + 拉满层 + 保底层 + 牺牲层 + 八层参数 + 一句话总结
- [ ] 选参前查了该类型牺牲层禁选清单
- [ ] **牺牲层自证**：明文声明"选了___（次优），未选___（规整）"
- [ ] 一句话总结与八层参数一致

### 第三步：转中文 prompt
**指示**：方案转中文自然语言 prompt + 负面词（下游：通义万相/即梦）
**必须输出**：中文 prompt（≥80字）+ 负面提示词
- [ ] 组织顺序：主题服装→场景→瞬间→光影→色彩→构图→质感
- [ ] 主题词首尾各出现一次（锚定防漂移）
- [ ] 八层每层具体描述（无"简洁背景"糊词），≥80字
- [ ] 瞬间写临界（"嘴角将笑未笑"非"微笑/大笑"）
- [ ] 牺牲层正向写；心理层间接实现
- [ ] 负面词含：解剖崩坏 + 主题冲突服装 + 水印

细则 + demo 见 guidelines 第三步。

### 第四步：三问自检
**必须输出**：三问答案
- [ ] 类型明确（A/B/C，非"都要"）
- [ ] 压点指出具体层（非"整体好"）
- [ ] 牺牲点指出具体层（非"都不牺牲"）

### 第五步：出图
**指示**：调文生图模型生成
**必须输出**：图片
- [ ] 用第三步的 prompt + 负面词
- [ ] 用户附加约束（如不要背影）已在 prompt 强调

### 第六步：生成后自验
**必须输出**：自验报告（通过/不通过 + 原因）
- [ ] 主题服装未漂移（非汉服/日常服）
- [ ] 用户约束满足（如无背影）
- [ ] AI 崩坏检查（手/脸/解剖/一致性）
- [ ] **牺牲层真落实**（对照方案参数：构图真不规整？主体真切了？）
- [ ] 不通过调 prompt 重出，未交付带病图

自验只查技术层 + 约束，心动层留用户反馈或诊断流程。

## 场景二：诊断图片

走四步诊断，详见 [references/image-diagnosis-checklist.md](references/image-diagnosis-checklist.md)：

1. **分流**：看一眼后脑子里有没有"画面以外"的念头？有→心动在，走扫脏点；没有→心动断，走定位断点。
2. **心动在 → 扫脏点**：技术五层 checklist 逐条查（主体 / 构图 / 光影 / 色彩 / 质感），找出硬伤。
3. **心动断 → 定位断点**：四问对应叙事 / 瞬间 / 留白 / 距离感，每层带救法。
4. **一句话诊断 + 改造优先级**：套模板给病根，按 **距离感 → 瞬间 → 叙事 → 留白** 顺序逐层救（距离感没救，下面三层再补都是端着的图）。

---

## 关键规则（铁律）

- **生成前必须先问用户方向**，不准自己猜心动类型。方向错全歪。
- **用户选完方向后不追问变量**，AI 自动选全部参数一次性出方案，只在方案层面让用户确认或指改。
- **偏科铁律**：技术层 80 分保底，火力集中压 1~2 心动层，主动牺牲 1 层。"每层都做到位"= 平均用力 = 安全牌 = 最无聊。
- **按菜单选不要猜**：维度选项查 [references/image-structure-dimensions.md](references/image-structure-dimensions.md)，标【硬伤】的无论什么风格都避开，标【推荐】的通常更优。
- **生成是正向进攻，诊断是逆向归因**，别拿防守清单去进攻。

## 怎么组合使用

一条完整链路（生成 → 验 → 改 → 再生成）：

**生成路径**
1. 用户提任务 → 本 skill 第一步：AI 给推荐方向，用户选字母
2. 选定方向 → 第二步：AI 按菜单自动选八层参数，输出偏科方案，用户确认
3. 确认 → 第三步：方案转生成指令（prompt / brief / JSON）
4. 喂模型 / 摄影师 → 出图

**诊断路径**（图已有，或生成后不满意）
1. 拿到图 → 诊断第一步：分流，心动在不在
2. 心动在 → 扫脏点；心动断 → 定位断点
3. 一句话诊断 + 改造优先级

**迭代路径**
1. 诊断发现哪层断 → 回生成流程改那层偏科
2. 查 references/image-structure-dimensions.md 换该层选项
3. 重出方案 → 转 prompt → 再生成，循环直到心动
