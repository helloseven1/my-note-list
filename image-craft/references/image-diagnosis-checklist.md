# 图片诊断流程 · 找断点 + 开药方

> 这是**逆向归因**工具：图已经在了，逐层找"哪断了、怎么救"。
> 生成准则见 `image-generation-guidelines.md`（正向进攻），维度定义见 `image-structure-dimensions.md`。
> 三份文档关系：维度定义 = 是什么；生成准则 = 怎么造；本文 = 怎么测 + 怎么救。

---

## 诊断总原则

诊断不是"挑每一处毛病"，是**定位最断的那一层，只改它**。

一张图可能技术层有几处小脏点、叙事层也略空，但真正让它"不心动"的往往只有**一层**。把那层找出来、改掉，比到处修修补补有效十倍。到处修 = 平均补强 = 还是安全牌。

---

## 第一步：先分流——心动在不在

拿到图别急着评构图光影，先问一个总问题：

> **看一眼之后，脑子里有没有留下一个"画面以外"的念头？**

（比如：想知道她接下来会做什么 / 想知道她在看什么 / 觉得有点心疼 / 想知道她刚才发生了什么）

- **有** → 心动力在，问题在技术层。**跳到第二步**（扫脏点）。
- **没有**（看完只记得"哦一个人"）→ 心动力断了。**跳到第三步**（定位断点）。

这一步先分流，别在没心动的图上浪费时间抠光影——光影修再干净，不心动还是不心动。

---

## 第二步：心动在 → 技术层扫脏点

先分流诊断对象，硬伤清单不同：

**A. AI 生图**（通义万相/即梦/MJ/SD 产出）——查 AI 常见崩坏：
- [ ] 解剖：手部（六指/扭曲/融合）、关节（肘膝反弯）、肢体比例失调
- [ ] 面部：眼神空洞、瞳孔不对称、面部左右不对称、牙齿异常、远距离人脸崩
- [ ] 一致性：左右手不一、衣物左右穿帮、道具逻辑错、双眼完全雷同（对称过头）
- [ ] 物理逻辑：悬浮物体、穿模、重力错误
- [ ] AI 味：塑料感、过度平滑、过度完美、风格化腻味
- [ ] 文字：乱码水印（除非刻意要中文文字）

AI 生图崩坏属于"生成层硬伤"，直接重出图（prompt 加负面词或换描述），不走下面的摄影脏点清单。

**B. 真实摄影**——按一→二→三→四→五层顺序走，找"刺眼"的具体毛病：

### 主体层
- [ ] 表情僵不僵？有没有"摆"的痕迹？
- [ ] 眼神有没有失焦（看镜头看得很空，像看墙）？

### 构图层
- [ ] 景别合不合适？特写切在关节上（手腕、脚踝、膝盖）是硬伤
- [ ] 头顶留白太多（空）还是太少（压）
- [ ] 主体有没有被背景线条"切头/切脖/穿头"

### 光影层
- [ ] 顶光直打鼻子 → "胡须阴影"硬伤
- [ ] 逆光有没有补脸，脸黑成剪影（除非就是想要剪影）
- [ ] 背景有没有杂光亮斑抢视线
- [ ] 光比是不是过强导致高光死白 / 暗部死黑无层次

### 色彩层
- [ ] 肤色偏色没有（发青 / 发橙 / 发紫）
- [ ] 背景色和肤色撞不撞（同色相融成一坨）
- [ ] 后期色调是不是"为风格而风格"（明明不搭硬套青橙/胶片）

### 质感层
- [ ] 磨皮磨成塑料（无纹理 = 假）
- [ ] 焦点落点对不对——**人像焦点必须在眼**，落在鼻尖/耳朵都错
- [ ] 锐度是不是过头（发丝/边缘有白边 = 锐化过度）

**脏点找出来 → 逐条改。** 技术层问题都是"具体毛病"，指出来就能修。

---

## 第三步：心动断了 → 定位断在哪一层

这是诊断核心。问四个问题，对应叙事 / 瞬间 / 留白 / 距离感四层：

### Q1. 这张图讲了个什么场景？（测叙事层）

- **答不上来 / "就是一个人站着"** → 叙事层断。
  - 症状：环境、道具、时间感三件套至少缺两件，主体成"无根浮萍"。
  - **救法**：三选一补上——
    - 给环境（窗边 / 床沿 / 巷子 / 地铁）
    - 给道具（一杯水 / 一件外套 / 一本翻开的书）
    - 给时间感（逆光黄昏 / 深夜台灯 / 晨光冷调）
  - 别贪多，**补一个就够**，多了又变平均用力。

### Q2. 抓的是动作/表情的哪一帧？（测瞬间层）

- **是"笑完了 / 姿势摆好定型了"** → 瞬间层断。
  - 症状：抓的是动作的尾巴，不是临界点。
  - **救法**：改连拍，找**将起未起**——
    - 嘴角刚要上扬（还没笑出来）
    - 转身转到一半
    - 手指刚碰到头发
    - 眼神刚从别处转回镜头（还没定住）
  - 临界点自带张力，定型帧是死的。

### Q3. 画面里有没有"没说完的话"？（测留白）

- **所有信息都交代清楚**（背景全实、表情完整、动作到位、主体全身入画）→ 留白断。
  - 症状：观者无参与感，看完即走。
  - **救法**：三招任选——
    - 虚掉背景，只留氛围色块
    - 让视线落**画面外**（看画外比看镜头更勾人）
    - 用遮挡藏主体一部分（玻璃/门框/人群）或侧脸朝向不给你看全（≥50%铁律，不准切景别把人切碎）
  - 用"不完整"逼观者脑补。

### Q4. 拍的时候是"想让人心动"还是"在记录当下"？（测距离感/心理层）

- **能感觉到"这张在要我的反应"** → 距离感断，刻意感一来心动立刻死。
  - 症状：太端着（像杂志硬广）或太刻意（像在撩你），都死。
  - **救法（最难，因为发生在拍摄意图里，不在后期）**：
    - 从"摆给你看"改成"她在她的世界里，你只是偶然撞见"
    - 模特不看你，或看你的眼神是"穿过你"而不是"对着你"
    - 加物理隔断（玻璃 / 门框 / 人群），制造"你在看一个不为你存在的场景"

---

## 第四步：一句话诊断模板

套这个句式，病根就出来了：

> 技术层（一~五）做到 X 分，但**叙事缺 ___，瞬间抓的是 ___，留白 ___，距离感 ___**，所以不心动。

### 实例

> "光影构图 75 分，但叙事缺环境和时间感（白墙无道具），瞬间抓的是笑定型的尾巴，留白为零（全身入画全实），距离感偏端着（直视镜头像硬广）。所以——一张干净的证件照升级版，不心动。"

诊断到这个粒度，下一步"怎么改"就清晰了：**精准改最断的那一层**，不是"再多拍几张试试"。

---

## 改造优先级（断点多时怎么排序）

一张图可能四层都断。别同时改，按这个顺序逐层救：

1. **先救距离感**（最难、最底层、改了心态才有后面）→ 拍摄意图层面
2. **再救瞬间**（重拍成本高但效果立竿见影）→ 换连拍临界点
3. **再救叙事**（补一个环境/道具/时间感即可）→ 单点注入
4. **最后救留白**（后期也能补救一部分）→ 虚背景 / 遮挡 / 引视线

距离感没救，下面三层再怎么补都是"端着的图加点料"，还是不心动。

---

## 诊断结论 → 生成调整映射

诊断出哪层断后，回生成流程具体怎么改：

| 断点 | 生成调整动作 |
|---|---|
| 叙事断 | 补环境/道具/时间感三选一；道具加使用痕迹；prompt 补场景描述 |
| 瞬间断 | 改连拍找临界点；prompt 把"微笑"改"嘴角将笑未笑"、加"将语未语" |
| 留白断 | 虚背景/引视线画外/遮挡藏主体；prompt 加"浅景深""视线看向画面外" |
| 距离感断 | 主体不直视镜头/加物理隔断；prompt 改"穿过镜头的眼神""隔玻璃""她在自己的世界" |
| 技术硬伤（AI 生图崩坏） | 直接改该层选项或重出图加负面词，**不动偏科配方** |
| 技术硬伤（摄影脏点） | 查 dimensions 换该层选项，**不动偏科配方** |

**关键**：技术层硬伤只改该层选项、不动偏科配方；心动层（叙事/瞬间/留白/距离感）断了才动偏科配方，可能要换拉满层或牺牲层。技术问题是"执行错"，心动断是"方向错"，两回事。

---

## 诊断 vs 生成：别用错文档

| 场景 | 用哪份 |
|---|---|
| 图已经有了，想知道为什么不心动 | 本文档（诊断） |
| 还没拍/还没生成，要决定怎么拍 | `image-generation-guidelines.md`（生成准则） |
| 忘了某层定义/权重 | `image-structure-dimensions.md`（维度基础） |

**别拿诊断文档当生成准则**——诊断教的是"别断"，生成要的是"主动偏科造心动"，方向相反。拿防守清单进攻，只会拍出"没有明显毛病但也不心动"的安全牌。
