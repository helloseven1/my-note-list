# 图片结构维度 · 选项菜单全集

> 这是**选项菜单**，不是定义概览。
> 八层维度，每层拆成子维度，每个子维度列出 90% 常见选项。
> AI 生成时**按菜单选**，不要自己猜——猜出来的东西不同模型五花八门，准则就废了。

## 一、主体层（拍的是什么）

### 1.1 对象类型
单人 / 双人（互动）/ 双人（并列）/ 群体 / 自拍 / 局部（手 / 背影 / 侧脸 / 锁骨 / 肩 / 发尾 / 唇 / 眼）

### 1.2 姿态
站 / 坐（正坐 / 侧坐 / 抱膝 / 翘腿）/ 躺（仰 / 侧 / 趴）/ 倚靠（靠墙 / 靠窗 / 靠家具）/ 走动中 / 蹲 / 趴 / 动态（跑 / 跳 / 转身 / 伸展）/ 静止放松 / 弯腰 / 回头

### 1.3 朝向
正面 / 三分之二侧（最常用）/ 半侧 / 全侧 / 背影 / 回眸（半转）/ 仰头 / 低头 / 偏头

### 1.4 神态情绪

### 1.5 眼神方向
直视镜头 / 看画外某点（最勾人）/ 看画面内物体 / 闭眼 / 垂眸 / 向上看 / 向下看 / 侧看 / 半闭（慵懒）

### 1.6 眼神质感
聚焦（有内容）/ 涣散（走神）/ 湿润（含泪 / 水光）/ 锐利（对峙）/ 空洞（无神）/ 眯起（笑意 / 警觉）

### 1.7 状态真实度

## 二、构图层（怎么框住主体）

### 2.1 景别（= 亲密距离）
大特写（眼 / 唇局部）/ 特写（头颈肩）/ 近景（胸以上）/ 半身（腰以上）/ 大半身（膝以上）/ 全身 / 远景（人小环境大）/ 局部（手 / 脚 / 肩单独成画）

> **人物写真 ≥50% 铁律**：主景别必须 ≥ 半身（腰以上）。大特写 / 特写 / 近景 / 局部（单独成画）**禁选**——要距离感/留白用遮挡+朝向，不靠切景别。

### 2.2 机位高度
平视（最自然）/ 俯拍（娇小 / 保护欲）/ 仰拍（气场 / 仰望）/ 顶视（鸟瞰）/ 低角度（近贴地面）

### 2.3 拍摄距离
极近（冒犯 / 亲密）/ 近 / 中 / 远（疏离）/ 极远（渺小感）

### 2.4 主体位置
居中 / 三分法左 / 三分法右 / 边缘（逼仄感）/ 黄金分割点 / 偏下（留天空）/ 偏上（压迫）

### 2.5 构图形式
三分法 / 居中对称 / 对角线 / 三角形（稳定）/ S 形 / 框架构图（门 / 窗 / 拱 / 镜框）/ 引导线（路 / 栏杆 / 河流引向主体）/ 对称镜像 / 重复排列 / 留白主导 / 负空间 / 紧凑填充

### 2.6 留白方向
视线前方留白（推荐）/ 头顶留白 / 行进方向留白 / 四周均匀留白 / 无留白（满构图）

### 2.7 裁切方式
不裁（完整入画）/ 切额头上方（留头顶）/ 切发际线 / 切下巴以下 / 切关节之间（锁骨 / 腰 / 膝，安全）/ 切到关节（手腕 / 脚踝 / 肘，**硬伤**）/ 切掉半张脸 / 切掉身体大部分（**≥50%铁律禁**）

### 2.8 画幅比例
横构图（环境叙事）/ 竖构图（人像 / 手机屏）/ 方形（1:1 平衡）/ 全景宽幅（电影感）

## 三、光影层（光怎么塑形）

### 3.1 光质
硬光（直射阳光 / 裸灯，轮廓锐利、戏剧）/ 软光（柔光箱 / 阴天 / 窗纱漫射，细腻暧昧）/ 混合光（主硬副软）

### 3.2 光位
顺光（正面平，平淡但清晰）/ 前侧光（最常用，立体）/ 侧光 90°（强对比塑形）/ 侧逆光（轮廓光）/ 逆光（全逆，剪影 / 光晕）/ 顶光（头顶直下，**鼻子胡须阴影硬伤**）/ 底光（恐怖感）/ 伦勃朗光（前侧高位，脸颊三角光）/ 蝴蝶光（顶前，鼻下蝴蝶影）/ 环形光（正面环闪，无影）/ 分割光（侧强对比，阴阳脸）

### 3.3 光比
高对比（强明暗，戏剧冲突）/ 中对比（立体柔和）/ 低对比（平光，平和）/ 无影（均匀平光，证件照感）

### 3.4 光源类型
自然-直射阳光 / 自然-漫射（阴天 / 窗光）/ 自然-黄金时刻（日落前暖低角）/ 自然-蓝调时刻（日落后蓝紫）/ 自然-夜晚月光 / 人造-持续光（台灯 / 蜡烛 / 霓虹）/ 人造-闪光 / 人造-影棚灯 / 混合光（自然 + 人造）

### 3.5 阴影走向
无阴影 / 侧面阴影 / 下方阴影（顶光）/ 长投影（低角度光）/ 局部遮挡阴影 / 剪影（逆光全黑）/ 半剪影（轮廓 + 微弱细节）/ 树影斑驳 / 百叶窗条纹影

### 3.6 光斑 / 漏光
无 / 镜头光晕（逆光 flare）/ 丁达尔光束（体积光）/ 边缘漏光 / 前景光斑散景

### 3.7 补光方式
无补光（纯主光）/ 反光板补脸 / 双光源（主 + 副）/ 多光源包围 / 环境反射补光

### 3.8 光的方向感
单向单光源（明确方向）/ 多向多光源（复杂）/ 环境包围光（无方向，柔和）

## 四、色彩层（情绪的化学剂）

### 4.1 色调
暖调 / 冷调 / 中性 / 双色温（暖主冷辅 / 冷主暖辅）

### 4.2 色温
低色温（黄橙暖）/ 高色温（蓝青冷）/ 日光白平衡（准确）/ 故意偏色（偏黄 / 偏青 / 偏品红）

### 4.3 饱和度
高饱和（冲击）/ 中饱和（自然）/ 低饱和（高级克制）/ 局部饱和（肤色饱和 + 背景去饱和）/ 单色（黑白）/ 双色调（黑 + 单色）

### 4.4 明度
高调（亮，轻快 / 纯洁）/ 中调（日常）/ 低调（暗，神秘 / 压抑）/ 高调高反差（亮但硬）/ 低调高反差（暗但锐，电影感）

### 4.5 主色调
暖橙黄 / 冷蓝青 / 绿 / 红 / 粉 / 紫灰 / 大地色（棕褐米卡其）/ 黑白灰 / 多色均衡

### 4.6 配色关系

### 4.7 后期风格
数码干净（现代通透）/ 胶片-柯达（暖黄）/ 胶片-富士（青绿）/ 胶片-Portra 400（暖肤色低饱和）/ 胶片-Kodak Gold（金黄怀旧）/ 褪色怀旧（低饱和泛黄）/ 朦胧柔焦（梦幻）/ 低反差灰雾（电影感）/ 高反差锐利（时尚）/ 暗调电影（青橙 teal-orange）/ 法式浪漫（柔暖低对比）/ 日系清新（青蓝低饱和亮调）/ 暗黑系（低调冷）/ 复古胶片粗颗粒

### 4.8 肤色处理
真实肤色（准确）/ 偏暖肤色（健康 / 怀旧）/ 偏冷肤色（冷艳）/ 去饱和肤色（克制）/ 高光过曝肤色（梦幻）/ 古铜肤色（健康深色）

### 4.9 色彩情绪映射（选色参考）

## 五、质感细节层（能不能"摸到"）

### 5.1 景深
浅景深（强虚化，聚焦主体）/ 中景深 / 大景深（全景实，环境叙事）/ 移轴虚化（玩具感）

### 5.2 焦点位置
近眼（推荐）/ 远眼 / 双眼泛焦 / 嘴唇 / 手 / 道具 / 环境某点 / 多点平均

### 5.3 虚化类型
背景虚（最常用）/ 前景虚（遮挡柔化）/ 双向虚 / 无虚化（全景实）

### 5.4 焦外光斑
圆形光斑（优质镜头）/ 二线性（散景硬，**硬伤**）/ 旋转散景（Petzval 漩涡）/ 形状光斑（心形 / 星形，趣味）/ 光斑堆叠（点点灯光）

### 5.5 锐度
全局锐利（现代）/ 主体锐 + 背景柔（推荐）/ 全局柔（柔焦镜头 / 柔光镜）/ 过度锐化（白边，**硬伤**）

### 5.6 肌理呈现
皮肤纹理保留（真实）/ 轻磨皮（干净）/ 中磨皮 / 重磨皮塑料感（**硬伤**）/ 发丝清晰 / 布料质感 / 汗珠水珠 / 雀斑保留

### 5.7 颗粒
无颗粒（数码干净）/ 细颗粒（胶片感，推荐配胶片色调）/ 粗颗粒（高 ISO / 老胶片）/ 后期添加颗粒

### 5.8 噪点
干净无噪 / 轻微噪点（暗光自然）/ 明显噪点（高 ISO，质感）/ 彩色噪点（老胶片）

### 5.9 清晰度风格
清晰通透（现代数码）/ 朦胧雾化（加柔 / 起雾）/ 复古柔焦 / 锐利硬朗

## 六、氛围叙事层（场景讲什么故事）

### 6.1 场景类型
室内-卧室 / 室内-浴室 / 室内-客厅 / 室内-书房 / 室内-工作室 / 室内-咖啡馆酒吧 / 室内-酒店 / 室外-城市街头 / 室外-自然（森林 / 海边 / 山顶 / 田野 / 草原 / 沙漠）/ 室外-建筑（废墟 / 古典 / 现代玻璃）/ 室外-道路（公路 / 小巷 / 桥）/ 室外-水边（河 / 湖 / 池）/ 抽象纯色背景 / 影棚布景

### 6.2 道具（开放式，不限定清单）
道具举不完，**不要被固定清单限制**——列死反而缩小了想象空间。原则：任何能交代处境、身份、关系，或带"使用痕迹"的物件都可作为道具。

常见类别（仅作启发，不限于此）：
- 饮食类：杯 / 瓶 / 餐具 / 食物
- 纸质类：书 / 本 / 信 / 报纸 / 相片 / 票据
- 随身物：手机 / 耳机 / 相机 / 伞 / 包 / 眼镜 / 饰品
- 服饰延伸：外套 / 丝巾 / 帽 / 鞋 / 肩带（单独成道具）
- 环境物件：家具 / 镜子 / 窗帘 / 灯具 / 门
- 自然物：花 / 叶 / 水 / 雪 / 沙 / 石
- 情绪物：烟 / 酒 / 药 / 乐器
- 场景专属：按拍摄主题自然出现（如婚纱=捧花/头纱/戒指；校园=课本/单车；旅行=行李箱/车票；居家=抱枕/毛毯）——主题变了道具就变，所以绝不该有上限。

**关键不是"用什么道具"，是道具有没有使用痕迹 / 有没有交代处境**：
- 喝了一半的水 > 摆着的一杯水
- 翻开到某页的书 > 合上的书
- 滑落的肩带 > 整齐穿好的衣服
- 有痕迹 = 有叙事 = 有心动

### 6.3 时间感
清晨（冷调柔光，清新）/ 上午（明亮）/ 正午（硬光，少用）/ 午后（慵懒）/ 黄金时刻（日落前暖低角，推荐）/ 蓝调时刻（日落后蓝紫，情绪）/ 夜晚（人造光 / 月光）/ 深夜（私密暗调）

### 6.4 天气
晴天 / 多云 / 阴天（柔光）/ 雨天（湿润 / 反光）/ 雪天（冷白纯净）/ 雾天（朦胧层次）/ 风天（动势）/ 沙尘

### 6.5 季节
春（嫩绿清新）/ 夏（浓郁鲜活）/ 秋（暖黄落叶）/ 冬（冷白萧瑟）

### 6.6 叙事密度
无叙事（纯背景）/ 弱叙事（一处暗示）/ 中叙事（环境道具交代处境，推荐）/ 强叙事（明显故事场景）

### 6.7 留白来源（未交代信息）
动作未完成 / 视线落画外 / 表情将起未起 / 切掉关键部位 / 背景虚到只剩色块 / 时间不明确 / 关系不明确

### 6.8 情绪氛围
宁静 / 孤独 / 暧昧 / 张力 / 忧伤 / 欢快 / 神秘 / 危险 / 慵懒 / 期待 / 怀旧 / 压抑 / 自由 / 甜蜜 / 决绝

## 菜单标注说明

- **硬伤**：确定错误的选项（如切关节、顶光胡须阴影、磨皮塑料感、二线性散景、笑后定型），无论什么风格都应避开。
- **推荐**：该子维度下通常更优的选择。
